Deck details

Lower-case letters, numbers and dashes. Can't be changed later.

A title over four words is bumped one level up automatically. A single title can override this below, or with an "easy / medium / hard" column when importing.

Add a title

One title by hand, with an optional picture — quicker than an import file for a single addition.

Import titles

A .docx, .xlsx or .pdf list — every non-duplicate title is added to this deck. In a .docx or .xlsx table, a cell reading "easy"/"medium"/"hard" (or "سهل"/"متوسط"/"صعب") sets that row's own difficulty.

Import titles with pictures

A .xlsx with two or three columns (title, image filename, optional difficulty — row 1 is a header) and a .zip of those images (.png/.jpg/.webp, 5 MB max each). A title whose picture isn't found is still added, without one.
