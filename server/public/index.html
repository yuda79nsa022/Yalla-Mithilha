Import titles

Upload a .docx, .xlsx or .pdf list of names — every non-duplicate title is added to this deck directly. No size limit, so the whole list goes in at once.

Import titles with pictures

Two files: a .xlsx with two columns (title, image filename — row 1 is a header and is skipped), and a .zip containing those image files (.png/.jpg/.webp, 5 MB max each). Titles are matched to pictures by filename; a title whose filename isn't found still gets added, just without a picture.
